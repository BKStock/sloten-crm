# 第2章: 足りないもの

## 🔴 致命的（B2B販売の前に必須）

| # | 不足機能 | なぜ致命的か |
|---|---|---|
| 1 | **ログイン認証** | 今はURLアクセスで全データ丸見え。法律違反状態 |
| 2 | **PII暗号化** | 顧客の個人情報が平文。GDPR/個人情報保護法違反 |
| 3 | **監査ログ** | 誰が何をしたか記録がない。全規制当局で必須 |
| 4 | **配信制限ルール** | 過剰送信で規制当局に引っかかるリスク |

## 🟠 重要（最初の3社に売るために必要）

| # | 不足機能 | なぜ重要か |
|---|---|---|
| 5 | セルフオンボーディング | 新規顧客が自分で設定できないと売れない |
| 6 | メールビルダー（ノーコード） | テンプレ編集が開発者依存では使われない |
| 7 | 課金フロー（Stripe） | 自動請求ができないとSaaSにならない |
| 8 | KPIダッシュボード（グラフ） | FTD/GGR/入金推移が見えないと経営層が使わない |

## 🟡 差別化（20社以上に拡大するために必要）

| # | 不足機能 | なぜ必要か |
|---|---|---|
| 9 | ビジュアルジャーニーエディタ | D&Dで作れないとSolitics/Brazeに見劣り |
| 10 | A/Bテスト | 施策の最適化ができない |
| 11 | Gamification | ミッション/ルーレット/スクラッチ。iGaming特有要件 |
| 12 | GDPR対応 | 欧州展開の前提条件 |
| 13 | PAM連携（SoftSwiss等） | パートナー販売の前提 |

# 第8章: 技術アーキテクチャ

## 現在 → 将来

```
【現在】
Browser → CF Pages (HTML 132KB) → CF Functions → D1 / VPS API → BigQuery

【Phase 1】
Browser → CF Pages (Vite+TS) → CF Functions → D1(RLS) → BigQuery
                                  ↓
                               Clerk認証
                               Stripe課金

【Phase 2】
Browser → CF Pages (Next.js) → CF Workers → D1 + KV + Queues
                                  ↓            ↓
                               Clerk認証    BigQuery直接
                               Stripe課金   (VPS廃止)

【Phase 3】
マルチテナント完全分離 / Hyperdrive + PostgreSQL / Edge配信
```

## マルチテナント設計

```
方式: Row-Level Security（RLS）
全テーブルに tenant_id カラム追加
JWT に tenant_id / user_id / role を格納
全クエリに tenant_id フィルター自動注入
```

# 第9章: 法務 & コンプライアンス

## 現状のリスク（即対応必須）

| リスク | 深刻度 | 罰則 |
|---|---|---|
| 認証なし | 🔴 CRITICAL | GDPR: 最大€2,000万 or 売上4% |
| PIIが平文 | 🔴 CRITICAL | 同上 + 刑事責任の可能性 |
| 監査ログなし | 🔴 CRITICAL | ライセンス取得不可 |
| 同意なしマーケ | 🔴 HIGH | PECR: 最高£500,000 |

## 地域別ライセンス

| 地域 | ライセンス | 費用 | 期間 |
|---|---|---|---|
| EU/マルタ | MGA B2B Software Supplier | €25,000〜 | 6-12ヶ月 |
| UK | UKGC Gambling Software | £10,000〜 | 6-18ヶ月 |
| LATAM | LGPD準拠（DPA締結） | — | 30日 |
| 日本 | 個人情報保護法準拠 | — | 30日 |

## Responsible Gambling対応（UKGC必須）

```
□ Self-exclusion（GAMSTOP）連携
□ 問題ギャンブラー検知アラート
□ リスクスコアに基づくマーケ除外
□ クーリングオフ中のプロモ停止
```
