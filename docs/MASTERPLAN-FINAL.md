# PART 3: NBA（Next Best Action）エンジン

## アーキテクチャ

```
[イベント] → [特徴量計算] → [判定エンジン] → [制約チェック] → [実行]

特徴量: RFM / 予測LTV / チャーン確率 / RGスコア / ゲーム嗜好
判定:   Phase A=ルール5本 → Phase B=30本 → Phase C=MLモデル
制約:   RG除外 / コスト上限 / 疲労度制御 / 重複排除
実行:   Laaffic SMS / SendGrid / OneSignal Push / CRMアラート
```

## Phase A 即実装（5ルール）

```
IF 7日未ログイン AND 月次GGR>¥50K → VIP復活SMS
IF 入金失敗 AND リトライ<3 → 代替決済案内Mail（15分後）
IF ボーナス期限<48h AND 残高>¥0 → 消化リマインドPush
IF 累計入金が閾値突破 → VIP昇格SMS+Mail
IF FTD完了 → ウェルカムシーケンス開始
```

## 段階的進化

| Phase | エンジン | ルール数 | 精度 |
|---|---|---|---|
| A（Week 3） | ルールベース | 5 | 60% |
| B（Month 3） | 拡張ルール+スコアリング | 30 | 75% |
| C（Month 12） | ML（scikit-learn/LightGBM） | 自動 | 85%+ |

# PART 6: Responsible Gambling対応

```
□ 月間損失$500超ユーザーへの自動チェックメール
□ 自己排除（Self-exclusion）検知 → 全マーケ即時停止
□ CJタスク45: 責任あるギャンブル月次確認
□ 高リスクプレイヤーへのボーナス自動除外
□ LTV計算から問題ギャンブラーを除外するロジック
□ クーリングオフ期間中のプロモ配信完全停止
```
