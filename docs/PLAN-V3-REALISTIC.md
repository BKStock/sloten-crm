# 第1章: 批判チームの指摘と対応

## 😈 指摘1: 「12週MVPは願望」
**対応:** 24週（6ヶ月）に延長。移行→SaaS化の2段階に分離。

## 😈 指摘2: 「45社/18ヶ月は妄想」
**対応:** 36ヶ月で10-15社に下方修正。最初の12ヶ月は2-3社に集中。

## 😈 指摘3: 「$799は安すぎて怪しい」
**対応:** $2,500/月スタート。iGaming業界は「安い=信用できない」。

## 😈 指摘4: 「1人開発はベンダー審査で即失格」
**対応:** 正直に「創業者直接サポート、大企業より迅速」をUSPにする。最初の3社は紹介経由でDue Diligence回避。

## 😈 指摘5: 「D1でマルチテナントは賭け」
**対応:** Supabase（PostgreSQL + ネイティブRLS）に変更。

## 😈 指摘6: 「ライセンス費用が完全に抜けてる」
**対応:** Phase 1は**ライセンス不要の市場**（日本/アジア/LATAM）から。Phase 2でMGAライセンス申請。

# 第3章: カジノサイト連携設計

## Webhook受信（カジノ→CRM）— 22イベント

### リアルタイムイベント（Webhook即時受信）
```
player.registered          プレイヤー登録
player.email_verified      メール認証完了
kyc.document_submitted     KYC書類提出
kyc.approved               KYC承認 ★
kyc.rejected               KYC却下
deposit.initiated          入金開始
deposit.completed          入金完了（FTD判定含む）★
deposit.failed             入金失敗
game.session_started       ゲームセッション開始
game.session_ended         ゲームセッション終了 ★
bonus.claimed              ボーナス獲得
bonus.converted            ボーナス変換完了
withdrawal.requested       出金申請 ★
withdrawal.approved        出金承認
withdrawal.completed       出金完了
session.login              ログイン
session.logout             ログアウト
player.self_excluded       自己排除 ★★（即時対応必須）
player.limit_set           入金/損失制限設定
```

### バッチ同期（定期取得）
```
game.round_completed       ゲームラウンド詳細（1時間毎）
player.daily_stats         日次集計（毎日00:05）
player.monthly_stats       月次集計（毎月1日）
```

## コールバック（CRM→カジノ）— 5種

### 1. ボーナス付与リクエスト
```
POST /crm-callback/v1/bonuses/grant
→ ボーナステンプレートID + 金額 + 条件 + 有効期限
→ カジノ側でプレイヤーにボーナス反映
```

### 2. セグメント更新
```
PUT /crm-callback/v1/players/{id}/segments
→ add/remove タグリスト
→ カジノ側でプレイヤーグループ反映
```

### 3. VIPステータス変更
```
PUT /crm-callback/v1/players/{id}/vip-status
→ 新VIPレベル + 特典内容
→ カジノ側でVIP反映
```

### 4. 自己排除反映（CRITICAL）
```
POST /crm-callback/v1/players/{id}/exclusion
→ 全マーケティング即時停止
→ アクティブジャーニー即時退出
→ 監査ログ記録
```

### 5. プロモコード発行
```
POST /crm-callback/v1/promo-codes/generate
→ コード + 条件 + 有効期限
→ カジノ側で使用可能なコード生成
```
